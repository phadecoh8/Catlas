Notes:
- `apps/web/src/components/landing/landing-page.tsx` composes the landing page; the waitlist page (`join`) and its Supabase route are in the same app.
- Founder sign-in and waitlist review live in `apps/web/src/components/admin/` and `apps/web/src/app/admin/founder/`. Server handlers are under `apps/web/src/app/api/founder/`.
- `apps/web/supabase/schema.sql` creates the separate Supabase waitlist table.
- `apps/web` is the pnpm package `@catlas/web` (Next.js). `apps/api` is `@catlas/api` (Express). Paths in the docs and CI use those package names, for example `pnpm --filter @catlas/api db:generate`.
- Backend modules follow one pattern: `routes.ts`, `controller.ts`, `service.ts` and `schema.ts` (Zod).
- Middleware holds authentication, forced password change, role check, scope check (school, faculty, department, level), session lock, rate limiting, validation, cron authentication, audit and error handling.
- The cat SVG components (crying, happy, calm) live in `apps/web/src/components/cats/`. The product logo is `apps/web/public/logo.png`, copied from the owner's `Four columns.png` at the repository root; the favicon, app icons and social preview image are in the same public folder.
- Self-hosted fonts (Arimo and Tinos) are in `apps/web/public/fonts/` and declared in `apps/web/src/styles/fonts.css`.
- Agent instruction files at the root: `AGENTS.md` is the main file. `CLAUDE.md`, `GEMINI.md` and `CODEX.md` point to it.
